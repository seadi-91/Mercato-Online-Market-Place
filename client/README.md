## Google sign-in configuration

Set `NEXT_PUBLIC_GOOGLE_CLIENT_ID` in `client/.env` and use the same OAuth client ID as `GOOGLE_CLIENT_ID` in `server/.env`. Set `GOOGLE_CLIENT_SECRET` in `server/.env`.

In Google Cloud Console, configure the OAuth client as a Web application and add each frontend origin (for local development, `http://localhost:3000`; for deployment, the exact HTTPS frontend origin) under **Authorized JavaScript origins**. Sign-in uses Google's popup authorization-code flow, so the frontend and backend must use the same Google OAuth client. If using the callback route directly, also add the exact callback URL (`<frontend-origin>/auth/callback/google`) under **Authorized redirect URIs**.
